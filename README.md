## Завдання 1. Асинхронне сортування файлів

### Опис
Python-скрипт для сортування файлів за розширеннями з використанням асинхронного програмування.

### Функціональність
- Читання файлів із вихідної директорії.
- Створення папок відповідно до розширень файлів.
- Асинхронне копіювання файлів у відповідні папки.
- Обробка файлів різних типів.

### Технології
- Python
- asyncio
- pathlib
- shutil

### Запуск

```bash
python3 task_1.py -s </input> -o </output>
```

## Завдання 2. Аналіз частоти слів за допомогою MapReduce

### Опис
Python-скрипт для завантаження тексту з URL-адреси, аналізу частоти використання слів за допомогою парадигми MapReduce та візуалізації найчастіше вживаних слів.

### Функціональність
- Завантаження тексту з URL-адреси.
- Видалення знаків пунктуації.
- Розбиття тексту на окремі слова.
- Використання MapReduce для підрахунку частоти слів:
  - **Map** – перетворення слів у пари `(word, 1)`.
  - **Shuffle** – групування однакових слів.
  - **Reduce** – підрахунок кількості повторень кожного слова.
- Використання багатопотоковості (`ThreadPoolExecutor`) для паралельного виконання Map та Reduce.
- Візуалізація 10 найчастіше вживаних слів за допомогою горизонтальної діаграми.

### Технології
- Python
- requests
- matplotlib
- concurrent.futures
- collections
- string
